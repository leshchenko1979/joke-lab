# Joke Lab 🧪

An experimental repo for practicing joke creation through cycles:
**draft → review → fix → review → ... → perfect**.

**Rule:** every review runs against strict criteria.
The joke is NOT shown to the user until every criterion is green.
Maximum — 10 cycles per joke.

**Subject:** jokes about Sasha (10-year-old daughter of the user).

## Structure

```
cycle-01-domashka.en.md   — homework joke: "It's downloading"
cycle-02-sovest.en.md     — conscience joke: "Waiting for a call"
methodology.en.md          — review criteria and step-by-step creation guide
```
