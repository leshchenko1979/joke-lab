# Joke Lab 🧪

Экспериментальный репозиторий для отработки методологии создания
анекдотов через циклы: **черновик → ревью → исправление → ревью → ... → идеал**.

**Принцип:** каждое ревью проверяется по строгим критериям.
Анекдот не показывается пользователю, пока все критерии не станут зелёными.
Максимум — 10 циклов на один анекдот.

**Объект исследования:** анекдоты про Сашу (10 лет, дочь пользователя).

## Структура

```
cycle-01-domashka.md   — анекдот про домашнее задание и «загрузку»
cycle-02-sovest.md     — анекдот про совесть и «важный звонок»
methodology.md         — критерии ревью и пошаговая схема создания
```
